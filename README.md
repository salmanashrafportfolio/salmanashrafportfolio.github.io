# Salman Bhatti React portfolio recreation

A responsive React/Vite portfolio recreation for Salman Bhatti.

## Requirements
- Node.js 18+ (Node 20 recommended)
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Project structure
```text
salman-bhatti-portfolio-recreation/
├── index.html
├── package.json
├── README.md
├── public/
└── src/
    ├── main.jsx
    ├── projects.js
    └── styles.css
```

## Customization
- Edit projects, testimonials, skills and travel content in `src/projects.js`.
- Images and clips live in `public/`.
- Page layout and the contact links are in `src/main.jsx`.
- Styling, responsive breakpoints and animation/hover states are in `src/styles.css`.

## Notes
The layout is an independent front-end recreation, not the original site's source code. All content and images come from https://msalmanbhatti.github.io/. It has no backend, analytics, or legal documents.
